# Новое русское вино

Сайт магазина авторского вина "Новое русское вино".

## Формат входных данных

Программа читает Excel-файл со следующими колонками:

| Категория | Название | Сорт | Цена | Картинка | Акция |
| --- | --- | --- | --- | --- | --- |
| Белые вина | Белая леди | Дамский пальчик | 399 | belaya_ledi.png | Выгодное предложение |
| Красные вина | Хванчкара | Александраули | 550 | hvanchkara.png | |
| Напитки | Чача | | 299 | chacha.png | |

Используйте `wine_catalog.xlsx` как образец: скопируйте файл, измените данные и передайте путь через аргумент запуска.

## Установка

```bash
git clone <URL_репозитория>
cd wine-master
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск

```bash
python3 main.py
```

```bash
python3 main.py --excel-path ./data/my_wines.xlsx
```

## Проверка

1. Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).
2. Убедитесь, что карточки сгруппированы по категориям.
3. Проверьте, что бейдж "Выгодное предложение" отображается только у отмеченных товаров.
